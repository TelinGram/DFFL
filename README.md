# ⬇️ دانلودر فایل + مرورگر وب (نسخه ۲)

✅ دانلود هر فایلی از هرکجا
✅ پشتیبانی از فایل‌های بزرگ چند گیگابایتی
✅ رمزگذاری روی فایل‌های دانلود شده (اختیاری)
✅ استفاده از aria2 برای دانلود سریع
✅ فشرده‌سازی خودکار و تحویل بصورت پارت‌بندی شده (هر پارت ۹۰ مگابایت)
✅ ذخیره‌سازی دائمی فایل‌ها در ریپازیتوری خودتان

---

## 🚀 نحوه استفاده

1. به تب **Actions** بروید.
2. سمت چپ روی **⬇️ 01- Download File** کلیک کنید.
3. روی دکمه‌ی **Run workflow** بزنید.
4. لینک(های) دانلود را با فاصله وارد کنید.
5. (اختیاری) حالت zip و رمز عبور را انتخاب کنید.
6. روی **Run workflow** کلیک کنید.

فایل‌ها در پوشه‌ی `downloads/` ریپازیتوری شما قرار می‌گیرند.

---

## 🧹 پاک‌سازی

برای حذف تمام فایل‌های دانلود شده، از workflow **🧹 03- Clean downloads folder** استفاده کنید.

---

## ⚠️ نکته‌ی مهم

- از این ابزار فقط برای دانلود فایل‌های شخصی و مجاز استفاده کنید.
- فایل‌های دانلودی را در ریپازیتوری public قرار ندهید (مگر اینکه مجاز باشد).
